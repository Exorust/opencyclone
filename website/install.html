Install

Put OpenCyclon on your phone.

It takes about 15 minutes the first time. You need a computer and a cable once. After that the phone works alone.

Before you start

What you need.

An Android phoneAndroid 12 or later. Built and tested on a Pixel 7.
A computer and a USB cablemacOS, Linux, or Windows. Only for the first setup.
A model accountChatGPT, OpenRouter, your own key, or a model on your network.
Way 1

Let your AI coding agent do it. Easiest

If you use Claude Code, Codex, Cursor, or Gemini CLI, connect the phone with a cable and give the agent this sentence:

Install OpenCyclon on my Android phone. Follow https://raw.githubusercontent.com/Exorust/opencyclon/main/INSTALL-WITH-AI.md

The agent checks your tools, gets the app, runs the setup script, and tells you what to tap on the phone. It never asks for your model key or your pairing code. You type those on the phone.

Way 2

Do it yourself in five steps.

1. Get the tools on your computer

  • Git and JDK 17. On macOS: brew install openjdk@17.
  • The Android SDK with platform 36. The simplest way is to install Android Studio and open its SDK Manager once.
  • adb, the tool that talks to the phone. It comes with Android Studio. On macOS you can also run brew install --cask android-platform-tools.

2. Prepare the phone

  1. Open Settings > About phone and tap Build number seven times.
  2. Open Settings > System > Developer options. Turn on USB debugging and Wireless debugging. Wi-Fi must be on.
  3. Connect the phone with the cable and accept "Allow USB debugging".
  4. Run adb devices. The phone must appear with the word device.

3. Build the app

git clone https://github.com/Exorust/opencyclon.git
cd opencyclon/android
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties
JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew :app:assembleStandardDebug
cd ..

The two paths are the macOS defaults. On Linux the SDK is usually in $HOME/Android/Sdk. The first build can take 10 minutes.

4. Install it and grant the permissions

./setup.sh

The script installs the app and turns on what the app cannot ask for itself: the accessibility service, notification access, the microphone, and notifications. Every line of its output starts with ok: or FAILED:.

5. Open the app on the phone

  1. Connect once. The app pairs with the phone's own wireless debugging. Follow the steps on the screen. After this you can remove the cable.
  2. Choose a model. Sign in with ChatGPT or OpenRouter, or enter your own key.
  3. Permissions and voice. Confirm what the script granted.
  4. Try it. Ask for something.

After a restart of the phone, open the app with Wi-Fi on and tap "Connect" again. You do not need the computer for that.

Help

If something fails.

What you seeWhat to do
SDK location not foundCreate android/local.properties with the sdk.dir= line from step 3.
FAILED: No device foundCheck the cable, accept the debugging question on the phone, and run adb devices.
FAILED: More than one deviceSet ANDROID_SERIAL to the serial number from adb devices, then run the script again.
The app says "Not connected"Turn on Wi-Fi and Wireless debugging, then tap "Connect" in the app.

Something else? Open an issue on GitHub. To remove the app, run adb uninstall ai.opencyclon.standard.
